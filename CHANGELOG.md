# Changelog

## 0.1.0 — first release

- Side panel that follows the TypeScript / TSX / JavaScript / JSX file you have open.
- One card per function: the code on the left, the translation on the right.
- Three translation styles in tabs: **In English**, **Pseudo English** and **Pseudo code**.
- **💡 Good to know** section explaining the JavaScript ideas each function uses (async/await, promises, destructuring, optional chaining, React hooks and more).
- **📄 About this file** overview: what the file is, what it uses and shares, and what each function does.
- **Show code** switch to hide the code column when the real file is open next to the panel.
- Optional **✨ Claude** tab and file summary, using your own Anthropic API key.
- Highlights the function under your cursor; clicking a card header jumps to it.
